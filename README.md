# Shewanella benthica pangenome

Code and data for the preprint:

> **Insertion-sequence expansion and acquired defence systems distinguish hadal strains in the pangenome of the piezophilic bacterium *Shewanella benthica***. 
> Laura E. Peralta-Guzmán, Hansel B. Lopez-Chevalier.      *bioRxiv* (2026). doi: [10.1101/XXXX.XX.XX.XXXXXX]

This repository contains the scripts used to build and analyse the Panaroo/eggNOG-mapper pangenome of four *S. benthica* strains: extraction of one representative protein per Panaroo family for eggNOG-mapper, construction of the family-level table, statistics, Figures 1–5 and the result tables behind Supplementary Tables S1–S10.

---

## Summary

*Shewanella benthica* is a psychropiezophilic gammaproteobacterium found in abyssal and hadal environments, down to the Challenger Deep. We built the pangenome of four strains, two non-hadal and two hadal:

| Strain | Habitat class | Isolation source | Depth (m) | Gene families | Strain-specific |
|---|---|---|---|---|---|
| BOEU19-1 | Non-hadal | Deep-sea sediment | unknown | 3,780 | 274 |
| DSM 8812ᵀ (= ATCC 43992ᵀ) | Non-hadal (abyssal) | Gut of the holothurian *Psychropotes longicauda* | 4,560 | 3,296 | 390 |
| DB21MT-2 | Hadal | Sediment, Challenger Deep, Mariana Trench | 10,898 | 3,798 | 680 |
| KT99 | Hadal | Amphipods, Kermadec Trench | 9,856 | 3,670 | 514 |

Assembly accessions: BOEU19-1, GCF_982680095.1; DSM 8812, GCF_015069875.1; DB21MT-2, GCF_900476435.1; KT99, GCF_000172075.1.

**Main findings**

- **Pangenome size.** 5,794 gene families: 1,893 core (32.7%), 2,043 accessory (35.3%) and 1,858 strain-specific (32.1%). The pangenome is provisionally open (Heaps' law γ = 0.34 ± 0.03).
- **Grouping by gene content.** The two hadal strains are most similar to each other (Jaccard 0.64), and so are the two non-hadal strains (0.63).
- **Core genome.** It carries the functions associated with the piezophilic lifestyle: the Pfa (EPA) synthase, two Na⁺-NQR gene sets, cytochrome *bd* oxidase and polyamine biosynthesis.
- **Strain-specific mobilome.** Strain-specific families are strongly enriched in mobile elements compared with the core (15.3% vs 0.1%; OR 171, *P* = 2 × 10⁻⁸⁸).
- **Transposases in the hadal strains.** 238 of the 248 strain-specific transposase families (96%) belong to the hadal strains: KT99 has 152 and DB21MT-2 has 86. Their dominant IS families differ.
- **Defence systems.** Type I-F CRISPR-Cas and type I restriction-modification systems occur only in the hadal strains. DB21MT-2 also has an extra TorRST–TorA (TMAO reductase) module.

## Requirements

- Python ≥ 3.10
- Packages listed in `requirements.txt`. The full workflow was re-run with Python 3.13, pandas 3.0, NumPy 2.5, SciPy 1.18, Matplotlib 3.11 and openpyxl 3.1; the original analysis used Python 3.10 (Supplementary Table S10). pandas 3.x needs Python ≥ 3.11; on Python 3.10, pip installs pandas 2.x, which also works.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

The figures use the **Liberation Sans** font, a metric-compatible Arial clone. If it is not installed, Matplotlib falls back to its default font and prints a warning. To change the font, edit `font.family` at the top of `scripts/figures.py`.

## Reproducing the analysis

The workbook `data/Q1_pangenome_results.xlsx` is included, so you can start at step 3. Steps 1–2 rebuild it from the Panaroo and eggNOG-mapper output (see [Upstream commands](#upstream-commands)).

```bash
# 1. One representative protein per Panaroo family -> input of eggNOG-mapper
python scripts/extract_representatives.py panaroo_output/ panaroo_family_representatives.faa

# 2. Merge Panaroo presence/absence with the eggNOG-mapper annotations
python scripts/pangenome_report.py panaroo_output/gene_presence_absence.csv \
    panaroo_family_eggnog.emapper.annotations data/Q1_pangenome_results.xlsx

# 3. Statistics, functional classes, IS families, trait inventory
python scripts/analysis.py data/Q1_pangenome_results.xlsx results/

# 4. Figures 1–5
python scripts/figures.py results/ figures/ data/Q1_pangenome_results.xlsx
```

Steps 2–4 take less than a minute on a laptop.

### Input

`data/Q1_pangenome_results.xlsx` must contain these sheets:

| Sheet | Content |
|---|---|
| `Master_functional` | One row per Panaroo family: `Panaroo_family`, `Genome_category`, `Strain`, `n_strains`, `Preferred_name`, `Description`, `COG_category`, `KEGG_ko`, `KEGG_Pathway`, `KEGG_Module`, `PFAMs` |
| `Intersections` | Exclusive strain combinations (`Combination`, `n_strains`, `Families`) |
| `Pangenome_compartments` | Core / accessory / strain-specific counts |
| `Family_frequency` | Number of families present in 1, 2, 3 and 4 genomes |

| File | Content |
|---|---|
| `results.json` | All summary statistics: Heaps' law fit, Jaccard indices, χ² tests, new genes per genome, etc. |
| `coverage.csv` | Annotation coverage (eggNOG, COG, KEGG) by compartment |
| `class_by_compartment.csv`, `class_by_strain.csv` | Curated functional classes |
| `subclass_by_strain.csv`, `subclass_by_compartment.csv` | Mobilome and defence subclasses |
| `IS_by_strain.csv` | Strain-specific transposases by IS family |
| `fisher_tests.csv` | Fisher's exact tests with Benjamini–Hochberg correction |
| `cog_enrichment.csv` | COG composition and enrichment versus the core |
| `subset_rarefaction.csv` | Exact pangenome and core sizes for all 15 strain subsets |
| `traits.csv` | Inventory of 26 deep-sea-related functional modules |
| `master.pkl` | Annotated family table (pandas pickle) |

## Methods overview

1. **Genomes.** Downloaded from NCBI with [ncbi-genome-download](https://github.com/kblin/ncbi-genome-download).
2. **Annotation.** Uniform re-annotation with [Prokka](https://github.com/tseemann/prokka).
3. **Pangenome.** Built with [Panaroo](https://github.com/gtonkinhill/panaroo) in strict clean mode with default thresholds (-c 0.98, -f 0.7). Core = 4/4 genomes, accessory = 2–3/4, strain-specific = 1/4. An independent pangenome was built with [anvi'o](https://anvio.org) from the same Prokka annotations (default `anvi-pan-genome` settings) for visualisation and rarefaction (Supplementary Figs. S1–S2).
4. **Functional annotation.** For each Panaroo family, the longest centroid recorded in the Panaroo graph was used as the representative protein (`extract_representatives.py`). These proteins were annotated with [eggNOG-mapper](https://github.com/eggnogdb/eggnog-mapper) v2.1.13 (DIAMOND, database v5.0.2), which provided COG categories, KEGG orthologues and Pfam domains. `pangenome_report.py` then merged the annotations with the Panaroo presence/absence table.
5. **Analysis.** `analysis.py` and `figures.py` then do the following:
   - Assign each family to one of nine curated functional classes. Rules are applied in this order: transposases/IS elements → prophages, integrases and plasmid functions → defence systems (CRISPR-Cas, R-M, TA/Abi) → primary COG letter.
   - Assign IS families from Pfam domains and descriptions.
   - Compute exact pangenome and core sizes for all 15 strain subsets, fit Heaps' law (n = K·N^γ) and calculate the mean number of new families over the 24 genome orderings.
   - Compute pairwise Jaccard similarity of gene content.
   - Test functional differences with χ² tests, and enrichment with two-sided Fisher's exact tests and Benjamini–Hochberg FDR correction.

### Upstream commands

These are the commands used for the study. Adjust paths to your installation. Software versions are listed in Supplementary Table S10.

```bash
# Genomes (ncbi-genome-download 0.3.3), one call per strain
ncbi-genome-download --genera "Shewanella benthica" -S $strain --formats fasta -o benthica_$strain bacteria

# Annotation (Prokka 1.15.6), one call per genome
prokka --kingdom Bacteria --genus Shewanella --species benthica --outdir annotated/Shewanella_benthica_${strain}_prokka genome.fna

# Pangenome (Panaroo 1.1.2; default -c 0.98 -f 0.7)
panaroo -i gff/*.gff -o panaroo_output --clean-mode strict -a core

# Representative proteins and functional annotation (eggNOG-mapper 2.1.13, database 5.0.2)
python scripts/extract_representatives.py panaroo_output/ panaroo_family_representatives.faa
emapper.py -i panaroo_family_representatives.faa -o panaroo_family_eggnog \
    --data_dir /path/to/eggnog_db --itype proteins -m diamond --cpu 24

# anvi'o 9 pangenome and rarefaction (Supplementary Figs. S1–S2)
anvi-gen-genomes-storage -e external-genomes.txt -o SHEWANELLA_BENTHICA_GENOMES.db
anvi-pan-genome -g SHEWANELLA_BENTHICA_GENOMES.db -T 24 -n Shewanella_benthica_pangenome
anvi-compute-rarefaction-curves -p Shewanella_benthica_pangenome/Shewanella_benthica_pangenome-PAN.db \
    --iterations 100 -O rarefaction
```

In `external-genomes.txt`, the anvi'o genome names use underscores (`BOEU19_1`, `DB21MT_2`), because anvi'o rejects hyphens in names.

## Caveats

- **Four genomes.** The openness of the pangenome is provisional, and phylogeny cannot yet be separated from habitat. The two hadal strains are also each other's closest relatives.
- **Draft assemblies.** KT99 is a draft genome. Fragmented assemblies can split IS copies and essential genes (for example, *dnaK* and *lon* appear as accessory), so the core genome reported here is a conservative estimate.
- **Annotation-based classification.** IS-family and defence-system assignments come from homology annotation and keyword/Pfam rules. Confirm them with ISEScan/ISfinder and DefenseFinder.
